Arch Linuxインストールハンズオン

Arch Linuxでデスクトップ環境であるKDEをインストールするまでのハンズオンです。

VirtualBox設定など

こちらからダウンロードできます。 世界各国にミラーがあるので好みのところからダウンロードできます。

VirtualBoxでインストールを行う場合、UEFIに設定します。 インストール時に以下にマークします。

初期インストール

詳しくはこちらを参照。

キーボードレイアウト

日本語キーボードレイアウトに設定します。

1

loadkeys jp106

インターネット接続

ネットワークインタフェースの確認とインタネットに接続してるかを確認します。

1
2

ip a
ping -c 3 google.com

システムクロックの更新

1

timedatectl set-ntp true

パーティション設定

ブロックデバイスが割り当てられているので、デバイスで確認します。 今回は仮想環境でやったため/dev/sdaですが/dev/nvme0n1などの場合もあります。

1

fdisk -l

パーティションの分割をします。 ここではEFIシステムパーティションを/dev/sda1、swapを/dev/sda2、rootパーティションを/dev/sda3とします。

EFIシステムパーティションは最低300MiB、Linux swapは512MiB以上に設定します。 IDはEFIパーティションはef00、swapは8200です。 残りはすべてrootパーティションとします。

1

cgdisk /dev/sda

任意のキーを押します。

NewとあるのでEFIシステムパーティションを設定します。

First sectorはそのままEnterキーを押してください。

Size in sectorsは300Mと入力します。

複数カーネルをインストールする場合は任意で調整してください。

Hex code or GUIDはef00と入力します。

名前をどうするか聞かれますがそのままEnterキーを押してもらって構いません。

free spaceを選択します。

Newでswapを設定します。

First sectorはそのままEnterキーを押してください。

Size in sectorsは512Mと入力します。

ここはお好みで調整してください。

Hex code or GUIDは8200と入力します。

名前をどうするか聞かれますがそのままEnterキーを押してもらって構いません。

free spaceを選択します。

Newでrootパーティションを設定します。

First sectorはそのままEnterキーを押してください。

今回は残りのスーペースすべてをrootパーティションとして使うためSize in sectorsはそのままEnterを押します。

Hex code or GUIDは8300と入力します。 ちなみにデフォルト値は8300なのでそのままEnterキーを押してもらっても構いません。

名前をどうするか聞かれますがそのままEnterキーを押してもらって構いません。

以下のようになれば成功です。

Writeを選択します。

yesと入力します。

Quitで抜けてください。

再度以下のコマンドでパーティションの分割ができたか確認してください。

1

fdisk -l

ミラーの選択

オプションですが、後でどうせやることになるので設定します。

1

vim /etc/pacman.d/mirrorlist

Server=https://mirrors.xtom.jp/archlinux/$repo/os/$archが非公式だが多分一番速い。

必須パッケージのインストール

1

pacstrap -K /mnt base linux linux-firmware base-devel vim networkmanager intel-ucode systemd

base、linux、linux-firmwareは必須です。 base-develもあったほうがいいでしょう。

テキストエディタはお好みのものをインストールしてください。 networkmanagerは後で使います。 systemdは必須パッケージに入ってるかも。

AMD CPUの場合amd-ucodeをインストールします。

fstabの生成

1

genfstab -U /mnt >> /mnt/etc/fstab

chroot

1

arch-chroot /mnt

タイムゾーン設定

日本の場合に置き換えてます。

1
2

ln -sf /usr/share/zoneinfo/Asia/Tokyo /etc/localtime
hwclock --systohc

ローカリゼーション

en_US.UTF-8 UTF-8とja_JP.UTF-8 UTF-8をアンコメントします。

1

vim /etc/locale.gen

ロケールを生成します。

1

locale-gen

以下のように環境変数を設定します。

1
2

echo "LANG=en_US.UTF-8" > /etc/locale.conf
echo "KEYMAP=jp106" > /etc/vconsole.conf

ネットワーク設定

ホストネームファイルを作成します。

1

hostnamectl set-hostname arch

archはお好みで変えてください。

NetworkManagerを有効化します。 これで次回から有線接続できるようになります。

1

systemctl enable NetworkManager.service

Initramfs

1

mkinitcpio -P

Rootパスワード

1

passwd

ブートローダー

ブートローダーをインストールします。 今回はsystemd-bootを使用します。

systemd-bootをインストールします。

1

bootctl install

ローダーの設定をします。 /boot/loader/loader.confを以下のように編集します。

default  arch.conf
timeout  3
console-mode max
editor   no

ローダーの追加を行います。 UUIDを使うので/boot/loader/entries/arch.confに書いときます。

1

blkid /dev/sda3 >> /boot/loader/entries/arch.conf

さらに/boot/loader/entries/arch.confを以下のように編集します。

title   Arch Linux
linux   /vmlinuz-linux
initrd  /initramfs-linux.img
initrd  /intel-ucode.img
options root=UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx rw

AMDプロセッサをお使いの場合、/intel-ucode.imgを/amd-ucode.imgに置き換えてください。

これで初期インストールは完了です。 chrootをexitで抜けrebootします。

一般ユーザー設定

rootでログインし先程設定したパスワードを入力します。

wheelグループにユーザーを追加します。 追加したユーザーにパスワードを設定します。 archはお好みで変えてください。

1
2

useradd -m -g wheel arch
passwd arch

先程作ったユーザーでsudoを使えるようにします。 %wheel ALL=(ALL:ALL) ALLをアンコメントします。

1

EDITOR=vim visudo

一度logoutし次はGUIをインストールしていきます。

KDEインストール

先程作成したユーザーにログインします。

AURヘルパーのインストール

1
2
3
4
5
6

sudo pacman -S git
git clone https://aur.archlinux.org/paru.git
cd paru
makepkg -si
cd
rm -rf paru/

PKGBUILDをマルチスレッドで圧縮できるようにします。 COMPRESSXZ=(xz -c -z -)をCOMPRESSXZ=(xz -T 0 -c -z -)に変更します。

1

sudo vim /etc/makepkg.conf

GPUドライバーなどのインストール

1

sudo pacman -S xorg-server xterm mesa

intelプロセッサでBroadwellより古い場合は不要です。

1

sudo pacman -S vulkan-intel

AMDGPUの場合以下をインストールすると良いです。

1

sudo pacman -S xf86-video-amdgpu vulkan-radeon rocm-opencl-runtime

フォントのインストール

Noto fontsを使います。

1

sudo pacman -S noto-fonts noto-fonts-cjk noto-fonts-emoji noto-fonts-extra

SDDMのインストール

1
2

sudo pacman -S sddm sddm-kcm
sudo systemctl enable sddm

今回はKDEなので標準のSDDMをインストールしましたが、GDMやLightDMなどの選択肢もあります。 詳しくはこちらを参照してください。

Plasmaのインストール

1

sudo pacman -S plasma-meta

今回はKDEをインストールしましたが、任意でGNOMEやXfceなどをインストールすることも可能です。

PipeWireのインストール

1
2

sudo pacman -S pipewire-jack pipewire-alsa pipewire-pulse
systemctl --user enable --now pipewire pipewire-pulse

ロケールとキーボードの設定

1
2

sudo localectl set-x11-keymap jp
sudo echo ja_JP.UTF-8 /etc/locale.conf

ここまでできたらrebootするとSDDMが起動するはずです。

GUIインストール後

日本語入力設定

fcitx5とmozcをインストールします。

1

sudo pacman -S fcitx5-im fcitx5-qt fcitx5-gtk fcitx5-mozc

fcitx5の設定をします。 ~/.config/environment.d/im.confを以下のように編集します。

XMODIFIERS=@im=fcitx
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
INPUT_METHOD=fcitx

なおその後の設定はこちらやこちらを詳しくは参照してください。
